OpenPose: Full-Body, Hand, and Face Detection

Note: OpenPose was scheduled for Week 4 but not covered due to time constraints. We're covering it now as it's essential for final projects.

What is OpenPose?

OpenPose is a real-time multi-person keypoint detection system developed at Carnegie Mellon University.

What It Detects:

  • Body: 18 keypoints (COCO model)
  • Hands: 21 keypoints per hand (42 total)
  • Face: 70 facial landmarks

Why OpenPose?

  • Multi-person detection (not just one person)
  • High accuracy
  • Real-time capable with GPU
  • Open source models
  • Industry standard for pose estimation

Body Keypoint Detection (COCO Model)

18 Body Keypoints (COCO Model):

0: Nose          9: RHip
1: Neck         10: RKnee
2: RShoulder    11: RAnkle
3: RElbow       12: LHip
4: RWrist       13: LKnee
5: LShoulder    14: LAnkle
6: LElbow       15: REye
7: LWrist       16: LEye
8: MidHip       17: REar
                18: LEar

Note: We're using the COCO model (18 keypoints), which is optimized for real-time performance and widely used in OpenCV implementations.

Implementation with OpenCV DNN:

import cv2
import numpy as np

# Load OpenPose model
protoFile = "models/openpose/pose_deploy_linevec.prototxt"
weightsFile = "models/openpose/pose_iter_440000.caffemodel"
net = cv2.dnn.readNetFromCaffe(protoFile, weightsFile)

# For best performance, use GPU
net.setPreferableBackend(cv2.dnn.DNN_BACKEND_CUDA)
net.setPreferableTarget(cv2.dnn.DNN_TARGET_CUDA)

cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    frameWidth = frame.shape[1]
    frameHeight = frame.shape[0]
    
    # Prepare input blob
    inpBlob = cv2.dnn.blobFromImage(
        frame, 
        1.0 / 255,                    # Scale factor
        (368, 368),                   # Input size (faster than 656x368)
        (0, 0, 0), 
        swapRB=False, 
        crop=False
    )
    
    net.setInput(inpBlob)
    output = net.forward()
    
    # output shape: [1, 19, H, W] where 19 = 18 keypoints + background
    H = output.shape[2]
    W = output.shape[3]
    
    # Extract keypoints
    points = []
    for i in range(18):  # 18 keypoints
        # Get heatmap for this keypoint
        probMap = output[0, i, :, :]
        
        # Find location of maximum confidence
        minVal, prob, minLoc, point = cv2.minMaxLoc(probMap)
        
        # Scale point to original image size
        x = (frameWidth * point[0]) / W
        y = (frameHeight * point[1]) / H
        
        if prob > 0.1:  # Confidence threshold
            points.append((int(x), int(y)))
            # Draw keypoint
            cv2.circle(frame, (int(x), int(y)), 8, (0, 255, 255), -1)
        else:
            points.append(None)
    
    # Draw skeleton connections
    POSE_PAIRS = [
        [1,0], [1,2], [1,5], [2,3], [3,4], [5,6], [6,7],
        [1,8], [8,9], [9,10], [10,11], [8,12], [12,13], [13,14]
    ]
    
    for pair in POSE_PAIRS:
        partA = pair[0]
        partB = pair[1]
        
        if points[partA] and points[partB]:
            cv2.line(frame, points[partA], points[partB], (0, 255, 0), 3)
    
    cv2.imshow('OpenPose', frame)
    
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

Performance Optimization for OpenPose

Critical for real-time performance:

# Strategy: Process at low resolution, display at high resolution

# Camera resolution (high for display quality)
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1280)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 720)

# OpenPose processing resolution (low for speed)
NET_INPUT_SIZE = (368, 368)  # Options: 368x368 (fast), 656x368 (accurate)

# Process at low resolution, scale keypoints back to full frame

Performance Tips:

  • Use GPU (CUDA): 20-30 FPS
  • Reduce net input size: 368x368 faster than 656x368
  • Skip frames if needed: process every 2nd or 3rd frame
  • Disable unused features: body-only is faster than body+hands+face

Gesture Recognition with OpenPose

Note: Gesture recognition is demonstrated here as a conceptual example. While not provided as a separate code file in the Week 5 examples, students can implement these techniques in their final projects.

Simple Gesture Detection:

def detect_t_pose(keypoints):
    """Detect T-pose: arms extended horizontally"""
    if keypoints[2] and keypoints[3] and keypoints[4] and \
       keypoints[5] and keypoints[6] and keypoints[7]:
        
        # Check if arms are roughly horizontal
        shoulder_level = keypoints[2][1]
        wrist_level = keypoints[4][1]
        
        if abs(shoulder_level - wrist_level) < 50:
            return True
    return False

def detect_hands_up(keypoints):
    """Detect both hands raised above head"""
    if keypoints[0] and keypoints[4] and keypoints[7]:
        nose_y = keypoints[0][1]
        right_wrist_y = keypoints[4][1]
        left_wrist_y = keypoints[7][1]
        
        if right_wrist_y < nose_y and left_wrist_y < nose_y:
            return True
    return False

Critical Considerations: Body Classification

OpenPose Makes Assumptions:

"Standard" Body:

  • 18 specific keypoints
  • Assumes bilateral symmetry
  • Expects certain proportions
  • Standing/sitting positions

What About:

  • Wheelchair users?
  • Prosthetic limbs?
  • Different body types?
  • Non-standing poses?
  • Children vs. adults?
  • Different clothing (robes, hijab)?

Performance Variations:

  • Works best on able-bodied adults
  • Standing poses more reliable than sitting/lying
  • Close-fitting clothing better than loose
  • May fail on unexpected body configurations

In Your Projects:

  • Test on diverse bodies
  • Don't assume everyone fits the model
  • Provide alternatives when detection fails
  • Be transparent about limitations
  • Consider: Who is your system designed for?

Neural Style Transfer

Now let's explore one of the most visually striking CV techniques: neural style transfer.

What is Neural Style Transfer?

Neural Style Transfer applies the artistic style of one image to the content of another.

The Classic Example:

  • Content image: photograph of a building
  • Style image: Van Gogh's "Starry Night"
  • Output: building painted in Van Gogh's style

Made Famous By:

  • Prisma app (2016)
  • Instagram/Snapchat filters
  • TikTok effects
  • AI art tools

How Neural Style Transfer Works

The Breakthrough Paper: "A Neural Algorithm of Artistic Style" (Gatys et al., 2015)

Core Insight: Convolutional neural networks (CNNs) trained for image classification learn both:

  • Content representation - what objects are in the image
  • Style representation - textures, colors, patterns

We can separate these and recombine them!

The Process:

  1. Content Representation: Higher layers capture content (objects, structures)
  2. Style Representation: Lower/middle layers capture style (textures, colors)
  3. Optimization: Iteratively adjust to match both content and style
  4. Result: Image with content of one, style of another

Fast Neural Style Transfer

The Solution: Train a network to do style transfer in one forward pass.

How It Works:

  • Train a separate network for each style
  • Input: content image → Output: stylized image
  • Single forward pass = fast!
  • Real-time capable (~20-30 fps)

This is what we'll use today.

Implementing Style Transfer with OpenCV

We'll use pre-trained fast style transfer models in Torch (.t7) format.

Basic Image Style Transfer:

import cv2
import numpy as np

# Load the style transfer model
net = cv2.dnn.readNetFromTorch('models/style_transfer/mosaic.t7')

# Load content image
content = cv2.imread('photo.jpg')
h, w = content.shape[:2]

# Prepare input blob
blob = cv2.dnn.blobFromImage(
    content,
    scalefactor=1.0,
    size=(w, h),
    mean=(103.939, 116.779, 123.68),  # ImageNet mean values
    swapRB=False,
    crop=False
)

# Apply style transfer
net.setInput(blob)
output = net.forward()

# Process output
output = output.reshape((3, h, w))
output = output.transpose(1, 2, 0)
output[0] += 103.939
output[1] += 116.779
output[2] += 123.68
output = np.clip(output, 0, 255).astype('uint8')

cv2.imshow('Original', content)
cv2.imshow('Stylized', output)
cv2.waitKey(0)
cv2.destroyAllWindows()

Performance Optimization

For Best Real-time Performance:

  1. Reduce processing resolution
  2. Use GPU (3-5x speedup)
  3. Lower camera resolution
  4. Skip frames if needed

Resolution vs Quality Trade-off:

  • 480px: Very fast, lower quality
  • 640px: Good balance
  • 800px: Better quality, slower

Background Removal & Segmentation

Image segmentation divides an image into meaningful regions. We'll focus on practical person segmentation for background removal and replacement.

Person Segmentation

What It Does:

  • Classifies every pixel as "person" or "background"
  • Creates a binary mask
  • Enables isolation and manipulation

Two Approaches:

  1. Deep Learning (Best Quality): Use semantic segmentation models (DeepLab); very accurate; requires model download; 20-30 FPS with GPU
  2. Background Subtraction (Simpler): Learn background, subtract to find foreground; no model needed; less accurate but fast; good for controlled environments

Background Removal

Basic Implementation:

import cv2
import numpy as np

# Simple approach: Background subtraction
bg_subtractor = cv2.createBackgroundSubtractorMOG2(detectShadows=False)

cap = cv2.VideoCapture(0)

# Learn background (step out of frame)
for i in range(30):
    ret, frame = cap.read()
    if ret:
        bg_subtractor.apply(frame)

# Now detect foreground
while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # Get foreground mask
    fg_mask = bg_subtractor.apply(frame)
    
    # Clean up mask
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_CLOSE, kernel)
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_OPEN, kernel)
    
    # Create green screen effect
    green_bg = np.zeros_like(frame)
    green_bg[:] = (0, 255, 0)
    
    # Composite
    mask_3ch = cv2.cvtColor(fg_mask, cv2.COLOR_GRAY2BGR) / 255.0
    result = (frame * mask_3ch + green_bg * (1 - mask_3ch)).astype('uint8')
    
    cv2.imshow('Background Removed', result)
    
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

Critical Considerations: Foreground vs Background

Segmentation is Classification:

Questions:

  • What's "foreground" vs "background"?
  • Assumes person is always foreground
  • What if environment matters more than person?
  • Whose perspective defines importance?

Practical Failures:

  • Hair segmentation often poor (especially textured hair)
  • Arms/hands frequently lost
  • Unusual clothing confuses models
  • Wheelchair users, assistive devices

Ethical Issues:

  • Background replacement in video calls (performative professionalism)
  • Erasing context and environment
  • Who can afford to be "foreground"?
